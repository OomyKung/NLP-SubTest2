SLAAC and DHCPv6 (IPv6 Dynamic Addressing)

IPv6 hosts can get a global unicast address (GUA) automatically in three ways: SLAAC only, SLAAC with stateless DHCPv6, or stateful DHCPv6. The router's ICMPv6 Router Advertisement (RA) message tells the host which method to use. A Cisco router sends RAs only after "ipv6 unicast-routing" is enabled.

SLAAC and DHCPv6 key terms:
- SLAAC (Stateless Address Autoconfiguration): the host builds its own GUA from the RA prefix. No server tracks addresses.
- Stateless DHCPv6: the address comes from SLAAC, but a DHCPv6 server gives other settings such as DNS server and domain name.
- Stateful DHCPv6: a DHCPv6 server assigns the address and other settings and keeps a binding table, like DHCPv4.
- Interface ID: the last 64 bits of the address, built with EUI-64 (MAC address with FFFE inserted and the 7th bit flipped) or generated randomly.

SLAAC and DHCPv6 RA flags:
- A flag (Autonomous address configuration): 1 means use SLAAC to create a GUA.
- O flag (Other configuration): 1 means get other information such as DNS from a stateless DHCPv6 server.
- M flag (Managed address configuration): 1 means use a stateful DHCPv6 server for the address.
Method 1 SLAAC only: A=1, O=0, M=0. This is the default on Cisco routers.
Method 2 SLAAC with stateless DHCPv6: A=1, O=1, M=0.
Method 3 stateful DHCPv6: A=0, O=0 or 1, M=1.

SLAAC and DHCPv6 how it works:
1. The host creates a link-local address and checks it with duplicate address detection (DAD).
2. The host sends a Router Solicitation (ICMPv6 type 133) to ff02::2, or waits for a periodic RA.
3. The router answers with a Router Advertisement (ICMPv6 type 134) that contains the prefix, prefix length, and A, O, M flags.
4. The host uses the router's link-local address as its default gateway.
5. If O or M is set, the host contacts a DHCPv6 server at multicast ff02::1:2.

SLAAC and DHCPv6 ports and messages:
DHCPv6 uses UDP port 546 for the client and UDP port 547 for the server. Messages are SOLICIT, ADVERTISE, REQUEST, REPLY, and INFORMATION-REQUEST. DHCPv6 does not give a default gateway; that always comes from the RA.

SLAAC and DHCPv6 Method 1 SLAAC only configuration:
R1(config)# ipv6 unicast-routing
R1(config)# interface g0/0/1
R1(config-if)# ipv6 address 2001:db8:acad:1::1/64
R1(config-if)# no shutdown
Hosts on 2001:db8:acad:1::/64 now create their own addresses. A Cisco router can be a SLAAC client with:
R2(config-if)# ipv6 enable
R2(config-if)# ipv6 address autoconfig

SLAAC and DHCPv6 Method 2 stateless DHCPv6 configuration:
R1(config)# ipv6 dhcp pool IPV6-STATELESS
R1(config-dhcpv6)# dns-server 2001:db8:acad:1::254
R1(config-dhcpv6)# domain-name example.com
R1(config-dhcpv6)# exit
R1(config)# interface g0/0/1
R1(config-if)# ipv6 nd other-config-flag
R1(config-if)# ipv6 dhcp server IPV6-STATELESS
The host keeps its SLAAC address. It sends a SOLICIT, gets an ADVERTISE, then sends an INFORMATION-REQUEST, and the server sends a REPLY with DNS and domain name. The pool has no address prefix.

SLAAC and DHCPv6 Method 3 stateful DHCPv6 configuration:
R1(config)# ipv6 dhcp pool IPV6-STATEFUL
R1(config-dhcpv6)# address prefix 2001:db8:acad:1::/64
R1(config-dhcpv6)# dns-server 2001:db8:acad:1::254
R1(config-dhcpv6)# domain-name example.com
R1(config-dhcpv6)# exit
R1(config)# interface g0/0/1
R1(config-if)# ipv6 nd managed-config-flag
R1(config-if)# ipv6 nd prefix default no-autoconfig
R1(config-if)# ipv6 dhcp server IPV6-STATEFUL

"managed-config-flag" sets M=1 and "no-autoconfig" sets A=0, so hosts do not also create a SLAAC address. The client exchange is SOLICIT, ADVERTISE, REQUEST, REPLY. A router client uses "ipv6 address dhcp".

SLAAC and DHCPv6 relay agent:
If the DHCPv6 server is on another network, configure the client-facing interface as a relay:
R1(config-if)# ipv6 dhcp relay destination 2001:db8::5

SLAAC and DHCPv6 verification:
Commands: show ipv6 interface g0/0/1, show ipv6 dhcp pool, show ipv6 dhcp binding, and ipconfig /all on Windows.
"show ipv6 interface" shows the method: "Hosts use stateless autoconfig for addresses" (SLAAC), "Hosts use DHCP to obtain other configuration" (O=1), or "Hosts use DHCP to obtain routable addresses" (M=1).

R1# show ipv6 dhcp pool
DHCPv6 pool: IPV6-STATEFUL
  Address allocation prefix: 2001:DB8:ACAD:1::/64 valid 172800 preferred 86400 (1 in use, 0 conflicts)
  DNS server: 2001:DB8:ACAD:1::254
  Active clients: 1
"show ipv6 dhcp binding" lists each client's DUID and leased address (stateful only).

SLAAC and DHCPv6 troubleshooting:
- No RAs: "ipv6 unicast-routing" is missing.
- Host gets a SLAAC address plus a DHCPv6 address: "ipv6 nd prefix default no-autoconfig" is missing.
- Host has an address but no DNS: O flag not set or pool not applied with "ipv6 dhcp server".

CCNA exam tips for SLAAC and DHCPv6:
- SLAAC only is the default; A=1, O=0, M=0.
- O flag = stateless DHCPv6; M flag = stateful DHCPv6.
- The default gateway always comes from the RA as the router's link-local address.

Common questions about SLAAC and DHCPv6:
Q: What is the difference between stateless and stateful DHCPv6?
A: Stateless DHCPv6 gives only other settings like DNS while the host uses SLAAC for its address; stateful DHCPv6 assigns the address and tracks it.

Q: Which RA flag enables stateless DHCPv6?
A: The O flag, set with "ipv6 nd other-config-flag".

Q: Which RA flag enables stateful DHCPv6?
A: The M flag, set with "ipv6 nd managed-config-flag".

Q: What ports does DHCPv6 use?
A: UDP port 546 for clients and UDP port 547 for servers.

Q: Why does a router not send Router Advertisements?
A: "ipv6 unicast-routing" must be enabled for a Cisco router to send RAs.
